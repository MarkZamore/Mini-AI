# Промежуточная модель для Mini-AI

По запросу пользователя подготовлен экспериментальный комплект Qwen3.5-4B для проверки AI-помощника до завершения основной подготовки.

Это публичная базовая модель без локального дообучения: текстовый Q6_K, CPU Windows x64, контекст 4096, четыре потока. Основная Qwen3.8-27B обучается отдельно. Локально сохранены её адаптер, код, журналы и обучающий набор. Сохранённый адаптер пригоден для дальнейшего дообучения; существующие checkpoints не содержат состояния оптимизатора для точного возобновления прерванного шага.

Комплект публикуется в [GitHub Releases](https://github.com/MarkZamore/Mini-AI/releases). Он не является итоговым результатом `model/instructions.md`: полная оценка русского/казахского RAG, проверка на чистой Windows, матрица памяти и длительные испытания ещё не завершены. Возможны ошибки фактов и цитирования. Результаты коротких реальных проверок включены в комплект.

Для установки:

1. Скачайте из промежуточного релиза в одну новую папку `model-core.zip`, `model-weights.part01`, `model-weights.part02`, `release-files.json` и `Assemble-model.ps1`.
2. Откройте PowerShell в этой папке и выполните `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Assemble-model.ps1`. Скрипт работает офлайн, соединяет части и проверяет SHA-256. Нужны около 8 GB свободного диска; установка программ и права администратора не требуются.
3. Закройте Mini-AI. Из созданной папки `Mini-AI-model-interim-4B` скопируйте **всю** папку `model` рядом с `Mini-AI.exe`. Существующую `model` сначала сохраните под другим именем. Не смешивайте файлы комплектов.
4. Запустите приложение. Для ответов по документам необходимы существующие папки `docs` и `db`; они не входят в модель и не заменяются. Для запуска worker требуется минимум 8 GiB свободной физической RAM.

Если приложения ещё нет, скачайте [опубликованный Mini-AI.exe](https://github.com/MarkZamore/Mini-AI/releases/tag/v2026.10.15-mini-ai). Предыдущий комплект данных находится в [релизе приложения и данных](https://github.com/MarkZamore/Mini-AI/releases/tag/v2026.10.15).

В публичный промежуточный релиз не входят приватный обучающий набор, исходные документы, пароли и средства подготовки Windows. Отдельный архив `Qwen3.8-27B-partial-adapter-step0150.zip` сохраняет недообученный адаптер 27B (шаг 150 из 246); он не является готовой папкой model или GGUF. `worker-source.zip` содержит исходники wrapper и сведения о закреплённом движке. Контрольные суммы опубликованных файлов находятся в `SHA256SUMS.txt`.

Публикация выполнена по прямому запросу пользователя без дополнительных проверок. Первое короткое задание RAG завершилось таймаутом ожидания кадра (120 секунд); успешный ответ по документам пока не подтверждён. Короткая обычная генерация через Mini-AI.exe прошла.

В тот же релиз добавлен более поздний `Qwen3.8-27B-partial-adapter-step0200.zip`: сохранение после 200 из 246 обновлений адаптера (800 из 984 обучающих примеров). Это резервная копия для дальнейшего дообучения, без состояния оптимизатора. Для запуска приложения используется прежний комплект 4B; архив адаптера 27B папку `model` не заменяет.
