# Mini-AI

Локальный помощник для Windows x64: поиск по базе нормативных документов,
ответы с источниками и граф связей. После подготовки комплекта для работы
помощника интернет не нужен.

**Полный portable-комплект: `v2026.10.24-local-ai`.**
Файлы комплекта и Markdown-отчёт находятся на
[странице релиза](https://github.com/MarkZamore/Mini-AI/releases/tag/v2026.10.24-local-ai).
Предыдущие версии сохраняются в [GitHub Releases](https://github.com/MarkZamore/Mini-AI/releases).

## Скачать и запустить

1. Скачайте **Mini-AI-setup.zip** и полностью распакуйте его в новую папку,
   например `C:\Mini-AI`.
2. Откройте **Установить-и-запустить.cmd**. Установщик сам скачает остальные
   части `Mini-AI.payload.partNNN`, проверит контрольные суммы приложения,
   модели, базы и источников, затем запустит Mini-AI. Вручную соединять или
   распаковывать части не нужно.
3. Для последующих запусков используйте **Запустить-на-процессоре.cmd** или
   **Запустить-на-NVIDIA.cmd**. Перед переключением режима закройте Mini-AI.

Готовому комплекту не требуются установленная Java, Python, права администратора
или авторизация на сайтах. Нужна Windows 10/11 x64 и не менее **9 ГиБ свободной
оперативной памяти** перед загрузкой модели. Во время подготовки место нужно
и для скачанных частей, и для распакованных файлов: ориентир для текущего
комплекта — около **25 ГБ свободного диска**. Установщик проверит точную
потребность до загрузки и извлечения.

Если загрузка прервалась, снова откройте установщик: он продолжит подготовку.
При несовпадении уже существующего файла он сохранит его и остановится;
для другой версии используйте новую папку.

## Процессор и NVIDIA

По умолчанию выбирается **процессор**. Это резервный режим совместимости:
в предыдущем исследовательском варианте 4B на текущем ноутбуке первый текст появился через
**174 секунды**, полный ответ — через **224 секунды**. Это один локальный
замер с дообученным E5, а не измерение новой foundation-конфигурации или обещание
скорости на другом компьютере. Точные результаты поставки будут в Markdown-отчёте.

Для ускорения генерации используйте **Запустить-на-NVIDIA.cmd**. Нужен
установленный драйвер, совместимый с CUDA 12.4. Поставляемый GPU-профиль
перед загрузкой требует не менее **11 ГиБ свободной видеопамяти**: бюджет
генератора 8 ГиБ и резерв 3 ГиБ. При недостатке ресурсов можно закрыть Mini-AI
и выбрать процессор; повторное скачивание модели не требуется.

В комплект входят **Qwen3.5-4B Q6_K** для генерации и исходный
**multilingual-e5-small (foundation E5)** для смыслового поиска.
Поиск объединяет E5 и лексический FTS/BM25. E5 работает через ONNX Runtime
на процессоре; режим NVIDIA ускоряет генератор 4B. В рабочем комплекте
используется исходный генератор 4B, а не экспериментальный адаптер QLoRA.

Локальное дообучение E5 сохранено в исследовании. Его кандидат отклонён:
улучшение поиска не обеспечило заранее требуемого прироста качества полных
ответов и выполнения условия об отсутствии роста критических ошибок.
Для поставки возвращён ранее зафиксированный контроль с foundation E5.
Это **рабочая резервная конфигурация**, нормативная надёжность её ответов
не подтверждена; существенные условия нужно проверять по оригиналам.

Оба режима сохраняют полный состав из семи модулей: помощник, база данных,
локальный вывод модели, документы, поиск, граф и открытие источников.

## Перенос всего комплекта

Сохраняйте **всю подготовленную папку**: `Mini-AI.exe`, корневые библиотеки
`vcruntime140.dll` и `vcruntime140_1.dll`, папки `model`, `docs`, `db`,
`native`, `licenses`, `profiles` и сценарии запуска. Модель, база,
производные артефакты источников и поставляемые библиотеки обязательны.
Папка исходников `src` получателю для запуска не нужна.

В комплекте сохраняются 599 документов и 106139 поисковых фрагментов.
Ссылки связываются с оригиналами и цепочками производных файлов по SHA-256.
Для открытия PDF и Office-документов нужна подходящая внешняя программа;
Mini-AI предлагает выбрать её через Windows Open With. Переход точно к
странице или ячейке внешняя программа не гарантирует.

В нормативных вопросах помощник опирается на найденные основания, показывает
источники и при нехватке данных должен уточнить запрос или сообщить о недостатке
подтверждения. Ответ и существенные условия следует сверять с оригиналом:
наличие ссылки само по себе не доказывает полноту ответа, а OCR не проходил
независимую ручную сверку.

## Подготовка без интернета

На другом компьютере заранее скачайте из **того же релиза** setup ZIP и все
опубликованные части `Mini-AI.payload.partNNN`. Распакуйте setup ZIP, положите
части в папку `downloads` рядом с установщиком и выполните:

```powershell
.\Установить-и-запустить.cmd -Offline
```

Проверить уже установленный комплект без запуска приложения:

```powershell
.\Установить-и-запустить.cmd -Offline -VerifyOnly -NoLaunch
```

После успешной подготовки папка `downloads` для работы помощника не требуется.
Контрольные суммы опубликованных файлов находятся в `SHA256SUMS.txt`;
установщик проверяет части и каждый файл комплекта автоматически.

## Исходники и сборка

Разработчику нужны Windows x64, GraalVM CE 25.0.2+10.1, MSVC 14.51.36231,
Windows SDK 10.0.26100.0 и Python для сборочных сценариев. Текущий portable
комплект собирается с профилем `native`. Из корня репозитория:

```powershell
.\src\build.ps1 -Action build -Profile native
```

Результат приложения появляется в `src/build/staging/EnterpriseAI`.
Полный runtime дополнительно включает утверждённые `model`, `docs` и `db`.
Сборка EXE сама по себе не создаёт готовый пользовательский релиз.

- [Архитектура и справка о профилях](src/README.md). Описание исторического
  профиля `static` не является составом текущего portable-комплекта.
- [GPU-worker и его подготовка](src/model-worker/README.md).
- [Сборка, проверка и публикация portable-комплекта](src/release-research/portable-PIPELINE.md).
- [Подключение другой базы](src/modules/search/CONNECTING-A-CORPUS.md).
- [Формат базы и ограничения извлечения](db/README.md).
- [Отдельный статический toolchain](src/toolchain/README.md); Cygwin нужен
  разработчику для этого отдельного маршрута, а не получателю portable-сборки.

**Проверять только полный текущий состав приложения.** По [AGENTS.md](AGENTS.md)
запрещены проверки отсутствующих модулей, `src/tests/module-removal`, матрицы
состава и отключение модулей ради испытаний. Отдельные проверки графа выполняются
только при изменении функций графа. Process Monitor исключён из обязательного
конвейера по указанию пользователя. Старые отчёты и контрольные суммы относятся
к указанным в них EXE и не заменяют приёмку новой сборки.

Локальные среды, модели обучения, checkpoints и результаты `src/build` в Git
не включаются. Исходники отправляются в репозиторий, готовый комплект —
в GitHub Releases.
