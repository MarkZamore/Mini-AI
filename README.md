# Mini-AI

Приложение Windows x64 на Java 25 для поиска по документам, просмотра связей в графе и работы с отдельно подготовленной локальной моделью. Текущая статическая сборка поставляется одним `Mini-AI.exe`; установленная Java, Python и отдельные DLL приложения для её запуска не требуются. Внутренние пакеты и сервисы сохраняют имя EnterpriseAI.

## Первоначальная подготовка комплекта для ноутбука

[Mini-AI для ноутбука: приложение, модель и подготовка всех данных](https://github.com/MarkZamore/Mini-AI/releases/tag/v2026.10.15-laptop-ready).

Скачайте `Mini-AI-laptop-setup.zip`, полностью распакуйте его и откройте `Установить-и-запустить.cmd`. В ZIP находятся EXE от 15 октября, библиотеки и модельный модуль. При первой подготовке сценарий скачивает ещё около 9,5 ГБ документов, артефактов и весов из закреплённых GitHub Releases, сверяет SHA-256 и запускает приложение. Требуется 25 ГБ свободного места. После подготовки закройте приложение, замените EXE версией от 17 октября по ссылке выше и запускайте его напрямую. Сценарий первоначальной подготовки закреплён за старой поставкой и не предназначен для повторной проверки обновлённого EXE.

Нужны Windows 10/11 x64, CPU с AVX2 и не менее 8 ГБ свободной ОЗУ. Исходная модель 4B ещё не дообучена на этих документах; формулировки из OCR следует сверять с цитатами. Реальная проверка на целевом ноутбуке остаётся за получателем. Подробная инструкция и вариант подготовки без интернета включены в ZIP.

## Поиск обычных вопросов и ответы модели

Обработка свободных вопросов добавлена 15.10.2026 в [коммите dd30ad2](https://github.com/MarkZamore/Mini-AI/commit/dd30ad25fcdf46d9f90bd2772cadb25ac3e3fb48). Сборка от 17.10.2026 сохраняет этот механизм и расширяет его для составных просьб вроде «Найди мне нормативный документ касаемо академической мобильности, напиши условия и дай рекомендации». Поиск отделяет тему от поручений по оформлению ответа и выбирает содержательные исходные фрагменты. Вопросительные и служебные слова, склонения русских заголовков и вопросы об организации обрабатываются по самой базе. Названия организаций в код не внесены; неизвестная тема не подменяется случайными совпадениями. Вопрос об организации получает до трёх подтверждающих фрагментов.

Отсутствие найденных фрагментов больше не завершает запрос фиксированным отказом: вопрос передаётся модели, которая формирует полезный общий ответ. Ответ без подтверждённых ссылок помечается «Общий ответ — без подтверждения документами базы.». Общие сведения отделяются от локальных требований; вымышленные ссылки не показываются. Поиск также понимает вопросы о правилах, порядке, обязанностях и прохождении практики, сохраняя ограничения темы, дат и фильтров.

Модель ссылается на короткие номера из текущего контекста. Приложение переводит их в исходные идентификаторы для цитат и истории; ссылки на несуществующие фрагменты не принимаются. Это избавляет небольшую модель от копирования длинных хешей и сохраняет проверяемые ссылки на оригиналы.

Текущий EXE от 17.10.2026 собран с профилем `static`: для переноса приложения нужны `Mini-AI.exe` и папки `docs`, `db`, `model`; установленная Java и отдельные DLL приложения не требуются. Комплект первоначальной подготовки выше остаётся отдельной поставкой с профилем `native` и прежними закреплёнными SHA; его архив не заменялся.

## Текущая версия и предыдущий релиз

Git-репозиторий содержит актуальные исходники и инструменты. [Текущий релиз Mini-AI](https://github.com/MarkZamore/Mini-AI/releases/tag/v2026.10.17-mini-ai) содержит `Mini-AI.exe`, `SHA256SUMS.txt` и публичный итог проверки `VERIFICATION.json`. Контрольная сумма и границы испытаний также описаны в [src/VERIFICATION.md](src/VERIFICATION.md). Для переноса нужны этот EXE и папки `docs`, `db`, `model` рядом с ним; папка `src` не нужна. Установленная Java, Python и дополнительные поставляемые DLL для запуска приложения не требуются.

Если папки данных уже есть, используйте их с новым EXE. Если данных нет, скачайте `EnterpriseAI-data.zip` и четыре архива `EnterpriseAI-artifacts-*.zip` из [предыдущего релиза](https://github.com/MarkZamore/Mini-AI/releases/tag/v2026.10.15), распакуйте их рядом с `Mini-AI.exe`, сохранив внутренние пути. Веса модели и `inference-worker.exe` в эти релизы не входят.

SHA-256 текущего EXE: `6afd2776be0f43e6a1909b83ed362f75ff6f15265b578a8add3847fed9819d9e` (315 772 928 байт). Предыдущая статическая сборка [v2026.10.15-mini-ai](https://github.com/MarkZamore/Mini-AI/releases/tag/v2026.10.15-mini-ai) сохранена отдельно.

Сборка от 17 октября 2026 года добавляет индикатор работы, этапы обработки и время ожидания над полем ввода; ответ появляется по мере генерации. Основа — `main` на коммите `aee93fd`, с сохранением обработки свободных вопросов и коротких цитат. Дополнительно исправлены вопросы о названии организации с оборотами «представленная в базе» и «документы которой представлены в базе»: эти слова распознаются как контекст вопроса, а дополнительные предметные ограничения сохраняются. [Отчёт проверки](src/VERIFICATION.md) относится к EXE текущего релиза.

Аудит Process Monitor пропущен по решению пользователя и исключён из обязательного конвейера. Отсутствие файловых и реестровых записей этой сборки не подтверждено завершённой трассой. Вопрос о правилах прохождения практики и общий вопрос без найденных источников проверены настоящим сервисом помощника с локальной моделью и базой в JVM; полный диалог через GUI, чистая Windows и целевой ноутбук не проверялись. Проверяется только текущая версия в полном составе; проверки отсутствующих модулей и вариантов приложения исключены. Отдельные проверки графа выполняются только при изменении его функций.

[Релиз v2026.10.15](https://github.com/MarkZamore/Mini-AI/releases/tag/v2026.10.15) содержит предыдущую сборку `EnterpriseAI.exe` и отдельно упакованные данные. Он не обновляется при отправке изменений исходников в Git. Для запуска именно этого предыдущего релиза:

1. Скачайте `EnterpriseAI.exe`, `EnterpriseAI-data.zip` и все четыре архива `EnterpriseAI-artifacts-*.zip` из релиза.
2. Поместите EXE в новую папку с коротким путём, например `C:\EnterpriseAI`. Распакуйте каждый ZIP в эту же папку, сохраняя внутренние пути. Все архивы артефактов обязательны.
3. Рядом с EXE должны находиться папки `docs`, `db` и `model`. Откройте `EnterpriseAI.exe`.

Веса модели и `inference-worker.exe` в предыдущий релиз не входят. Без них доступны поиск, граф и независимые функции приложения. Подготовка модельного комплекта описана в [model/instructions.md](model/instructions.md).

Для открытия исходных PDF и Office-документов нужна подходящая внешняя программа. Приложение предлагает выбор через Windows Open With.

### Проверка загрузок предыдущего релиза

В релизе опубликованы `SHA256SUMS.txt` с SHA-256 исполняемого файла, ZIP и манифеста, а также `EnterpriseAI-files.json` с путями, размерами и SHA-256 каждого файла комплекта. Например, контрольную сумму EXE можно получить в PowerShell:

```powershell
Get-FileHash -LiteralPath .\EnterpriseAI.exe -Algorithm SHA256
```

Сравните результат со строкой соответствующего файла в `SHA256SUMS.txt`. Порядок распаковки ZIP не имеет значения; все пути в них относительны общей папке приложения.

## Исходники и сборка

- [src/README.md](src/README.md) — архитектура, команды, профили сборки и ограничения.
- [src/toolchain/README.md](src/toolchain/README.md) — подготовка статического toolchain.

Для сборки нужны Windows x64, GraalVM CE 25.0.2+10.1, MSVC 14.51.36231, Windows SDK 10.0.26100.0, Python и Cygwin. Следуйте инструкции toolchain, затем из папки `src` выполните:

```powershell
.\build.ps1 -Action build -Profile static
```

Локальные результаты сборки, среды выполнения конвертера и кеши в Git-репозиторий не включены. Ссылки отчёта проверки на `src/build` относятся к локальным материалам испытаний. EXE публикуется отдельным файлом GitHub Release; исходники отправляются в Git.
