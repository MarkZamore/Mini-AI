# Mini-AI

Приложение Windows x64 на Java 25 для поиска по документам, просмотра связей в графе и работы с отдельно подготовленной локальной моделью. Обновлённая поставка содержит `Mini-AI.exe` и необходимые библиотеки; установленная Java или Python для её запуска не требуется. Внутренние пакеты и сервисы сохраняют имя EnterpriseAI.

## Скачать обновлённый комплект для ноутбука

[Mini-AI для ноутбука: приложение, модель и подготовка всех данных](https://github.com/MarkZamore/Mini-AI/releases/tag/v2026.10.15-laptop-ready).

Скачайте `Mini-AI-laptop-setup.zip`, полностью распакуйте его и откройте `Установить-и-запустить.cmd`. В ZIP уже находятся обновлённый EXE, библиотеки и модельный модуль. При первой подготовке сценарий скачивает ещё около 9,5 ГБ документов, артефактов и весов из закреплённых GitHub Releases, сверяет SHA-256 и запускает приложение. Требуется 25 ГБ свободного места. В дальнейшем запускайте `Mini-AI.exe` без интернета; сохраняйте весь готовый набор, включая `native`, DLL и папки данных.

Нужны Windows 10/11 x64, CPU с AVX2 и не менее 8 ГБ свободной ОЗУ. Исходная модель 4B ещё не дообучена на этих документах; формулировки из OCR следует сверять с цитатами. Реальная проверка на целевом ноутбуке остаётся за получателем. Подробная инструкция и вариант подготовки без интернета включены в ZIP.

## Локальное исправление поиска обычных вопросов

Локальная сборка от 15.10.2026 в корне проекта обрабатывает вопросительные и служебные слова, склонения русских заголовков и вопросы об организации по исходным фрагментам самой базы. Названия организаций в код не внесены. Даты, идентификаторы и смысловые слова остаются обязательными условиями поиска; неизвестная тема не подменяется случайными совпадениями. Вопрос об организации получает до трёх подтверждающих фрагментов.

Модель ссылается на короткие номера из текущего контекста. Приложение переводит их в исходные идентификаторы для цитат и истории; неизвестные номера отклоняются. Это избавляет небольшую модель от копирования длинных хешей и сохраняет проверяемые ссылки на оригиналы.

Эта локальная сборка использует переносимый профиль `native`: сохраняйте вместе `Mini-AI.exe`, `vcruntime140.dll`, `vcruntime140_1.dll`, папки `native`, `licenses`, `docs`, `db`, `model`. Установленная Java не нужна. Копирования одного EXE для переноса этой сборки недостаточно. Опубликованный ранее релиз ниже остаётся отдельной статической сборкой; его SHA не относится к локальному исправлению.

## Текущая версия и предыдущий релиз

Git-репозиторий содержит актуальные исходники и инструменты. [Текущий релиз Mini-AI](https://github.com/MarkZamore/Mini-AI/releases/tag/v2026.10.15-mini-ai) содержит `Mini-AI.exe`. Его контрольная сумма и границы испытаний описаны в [src/VERIFICATION.md](src/VERIFICATION.md). Для переноса нужны этот EXE и папки `docs`, `db`, `model` рядом с ним; папка `src` не нужна. Установленная Java, Python и дополнительные поставляемые DLL для запуска приложения не требуются.

Если папки данных уже есть, используйте их с новым EXE. Если данных нет, скачайте `EnterpriseAI-data.zip` и четыре архива `EnterpriseAI-artifacts-*.zip` из [предыдущего релиза](https://github.com/MarkZamore/Mini-AI/releases/tag/v2026.10.15), распакуйте их рядом с `Mini-AI.exe`, сохранив внутренние пути. Веса модели и `inference-worker.exe` в эти релизы не входят.

SHA-256 текущего EXE: `348f7b789183caef4eb924d9c6f5a265ffa97bb9e2fbb582192ab3110a65a251` (315 076 608 байт).

Аудит Process Monitor пропущен по решению пользователя и исключён из обязательного конвейера. Отсутствие файловых и реестровых записей этой сборки не подтверждено завершённой трассой. Проверки настоящей модели и чистой Windows остаются вне выполненных испытаний. Проверяется только текущая версия в текущем составе; проверки разных модулей и вариантов приложения исключены из конвейера.

[Релиз v2026.10.15](https://github.com/MarkZamore/Mini-AI/releases/tag/v2026.10.15) содержит предыдущую сборку `EnterpriseAI.exe` и отдельно упакованные данные. Он не обновляется при отправке изменений исходников в Git. Для запуска именно этого предыдущего релиза:

1. Скачайте `EnterpriseAI.exe`, `EnterpriseAI-data.zip` и все четыре архива `EnterpriseAI-artifacts-*.zip` из релиза.
2. Поместите EXE в новую папку с коротким путём, например `C:\EnterpriseAI`. Распакуйте каждый ZIP в эту же папку, сохраняя внутренние пути. Все архивы артефактов обязательны.
3. Рядом с EXE должны находиться папки `docs`, `db` и `model`. Откройте `EnterpriseAI.exe`.

Веса модели и `inference-worker.exe` в предыдущий релиз не входят. Без них доступны поиск, граф и независимые функции приложения. Подготовка модельного комплекта описана в [model/instructions.md](model/instructions.md).

Для открытия исходных PDF и Office-документов нужна подходящая внешняя программа. Приложение предлагает выбор через Windows Open With.

### Проверка загрузок предыдущего релиза

В релизе опубликованы `SHA256SUMS.txt` с SHA-256 исполняемого файла, ZIP и манифеста, а также `EnterpriseAI-files.json` с путями, размерами и SHA-256 каждого файла комплекта. Например, контрольную сумму EXE можно получить в PowerShell:

```powershell
Get-FileHash -LiteralPath .\EnterpriseAI.exe -Algorithm SHA256
```

Сравните результат со строкой соответствующего файла в `SHA256SUMS.txt`. Порядок распаковки ZIP не имеет значения; все пути в них относительны общей папке приложения.

## Исходники и сборка

- [src/README.md](src/README.md) — архитектура, команды, профили сборки и ограничения.
- [src/toolchain/README.md](src/toolchain/README.md) — подготовка статического toolchain.
- [src/VERIFICATION.md](src/VERIFICATION.md) — отчёт о проверке конкретного EXE и границы выполненных испытаний.
- [db/README.md](db/README.md) — формат базы, инструменты обработки и ограничения OCR.

Для сборки нужны Windows x64, GraalVM CE 25.0.2+10.1, MSVC 14.51.36231, Windows SDK 10.0.26100.0, Python и Cygwin. Следуйте инструкции toolchain, затем из папки `src` выполните:

```powershell
.\build.ps1 -Action build -Profile static
```

Локальные результаты сборки, среды выполнения конвертера и кеши в Git-репозиторий не включены. Ссылки отчёта проверки на `src/build` относятся к локальным материалам испытаний. EXE публикуется отдельным файлом GitHub Release; исходники отправляются в Git.
