ggml/src/ggml-backend-dl.cpp and ggml/src/ggml-backend-reg.cpp
were modified to disable dynamic library loading and backend discovery
and retain static CPU backend registration. The exact changes are in
llama-static-only.patch, supplied alongside this notice.

The native EnterpriseAI stdio wrapper and build configuration are local
integration code. They use statically linked engine and standalone
chat-template code, implement enterpriseai.inference.v1, validate the
model package and its hashes, and handle cancellation and pipe shutdown.
These integration changes are separate from model-weight training,
merging and quantization; the specific weight modifications must be
identified in that model's own preparation report and modification notice.
