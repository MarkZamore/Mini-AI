# Промежуточный комплект для проверки Mini-AI

Выпущен по запросу пользователя до завершения основной подготовки. Это Qwen3.5-4B без локального дообучения, текстовый Q6_K, контекст 4096, четыре CPU-потока. Обучение и длительная оценка 27B исключены из текущей цели по просьбе пользователя; сохранённый адаптер хранится отдельно.

Проверены реальная загрузка CPU-worker, короткие русские и казахские ответы, арифметика, отмена и следующая генерация, запуск через неизменённый опубликованный Mini-AI.exe. Это небольшая проверка работоспособности, а не полная оценка качества.

Минимум свободной физической RAM в manifest: 8 GiB; лимит процесса: 6 GiB. Это консервативные экспериментальные настройки, а не законченная матрица измерений. Подкачка не заменяет свободную RAM. Проверка на чистой Windows и на ноутбуке-получателе ещё не завершена. Возможны медленная генерация, ошибки фактов и ошибки ссылок на документы. Полная русская/казахская оценка RAG, сравнение BF16/адаптера/слияния/квантования и длительные испытания не завершены. Комплект не является итоговым результатом model/instructions.md.

Не требует установки Python, Java, CUDA или VC Redistributable для worker. Один статический Windows x64 EXE. Оригинальные docs/db и приложение не изменялись. Папка model не содержит исходных документов, обучающих примеров, адаптеров 27B, паролей или учётных данных. Адаптер 27B опубликован отдельным архивом для сохранения прогресса.

## Публикация папки model, 15 октября 2026

Комплект перенесён в корневую model по прямому запросу пользователя. В git опубликованы worker, manifest, лицензии и скрипт получения весов. Большие веса находятся в закреплённом GitHub Release; загрузчик проверяет обе части и итоговый GGUF. В текущей повторной проверке русского запроса по настоящему источнику приложение вернуло WORKER_TIMEOUT приблизительно через 135,5 секунды; успешный RAG-ответ не подтверждён. Предыдущая попытка проверки не стартовала из-за отсутствующего preparation-report.md в тестовой копии; этот дефект копии исправлен.
