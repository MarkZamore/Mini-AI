# Комплект модели Mini-AI

Полный пользовательский комплект распространяется через
[GitHub Releases](https://github.com/MarkZamore/Mini-AI/releases/tag/v2026.10.24-local-ai).
Скачайте `Mini-AI-setup.zip`, полностью распакуйте и запустите
`Установить-и-запустить.cmd`. Инструкции и требования — в [корневом README](../README.md).

Поставляемая конфигурация использует исходную Qwen3.5-4B Q6_K, исходную
multilingual-e5-small и её производный индекс. Локальное дообучение исследовано;
веса кандидатов сохранены отдельно и не приняты в рабочую поставку из-за
неподтверждённого улучшения полных ответов. Нормативная надёжность резервной
конфигурации также не доказана; существенные требования нужно сверять с источником.

В установленной папке `model` обязательны **все файлы из `worker.json`**, включая
worker EXE, веса, ONNX, tokenizer, векторный индекс, runtime DLL и лицензии.
Не смешивайте файлы разных комплектов. CPU выбран по умолчанию; отдельный
NVIDIA launcher переключает проверенные профили при закрытом приложении.

Репозиторий хранит исходники и инструкции; большие исполняемые комплекты,
веса и библиотеки поставляются файлами релиза. Исторические версии остаются
в прежних релизах и истории Git. Пользовательский `instructions.md` сохранён.
