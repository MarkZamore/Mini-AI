# Модель для Mini-AI, Windows x64 / CPU

Qwen3.5-4B Q6_K, без локального дообучения. Выбранный профиль: **контекст 16384, 12 CPU-потоков**. Worker использует AVX2; неподдерживаемый процессор отклоняется явно.
Требуется не менее 8 GiB **свободной** RAM. Около 8 GB свободного диска требуется при скачивании и сборке.

## Установка на другом ноутбуке

1. Скачайте `model-4b-laptop.zip` из [релиза модели](https://github.com/MarkZamore/Mini-AI/releases/tag/v2026.10.15-model-4b-laptop) и распакуйте. Либо скачайте папку `model` из репозитория. Большие веса хранятся отдельно; архив содержит worker, manifest, лицензии и загрузчик весов.
2. В папке `model` выполните:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Download-weights.ps1
   ```

   Скрипт скачает две закреплённые части, соберёт файл весов и проверит SHA-256. Права администратора и установка программ не нужны. Сеть нужна только для скачивания.
3. Закройте Mini-AI и разместите **всю** папку `model` рядом с `Mini-AI.exe`. Сохраните свои `docs` и `db`. Не смешивайте разные комплекты моделей.
4. Запустите приложение. Дальнейшая генерация работает офлайн.

Если части уже скачаны, можно собрать офлайн:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Download-weights.ps1 -LocalPartsDirectory 'D:\Downloads\Mini-AI'
```

## Проверенное состояние

С окончательным worker через неизменённый Mini-AI.exe пройдены короткие русское и казахское задания по переданным источникам: факты и цитаты проверены, ответы получены примерно за 35 секунд. Дополнительно проверены отмена во время генерации, следующий запрос в том же процессе и признание отсутствующего факта.

Для запроса «учебный план» поиск приложения вернул десять настоящих фрагментов и предупреждения семи документов. Запрос с теми же ролями и лимитом 1024 токена, которые использует Assistant, прошёл через worker: около 3,7 минуты, девять действительных ссылок. Первый текст появился примерно через 116 секунд. Пик working set — около 3,9 GiB на компьютере подготовки. Это не измерение скорости целевого ноутбука.

Во время долгой обработки worker посылает пустые текстовые кадры прогресса, разрешённые существующим протоколом. Они не являются словами ответа и предотвращают таймаут ожидания приложения. Обработка может занимать минуты; её можно отменить.

В предыдущей короткой проверке настоящего локального источника нужная цитата присутствовала, но модель добавила пояснения сверх запроса «только дословная цитата». Это ограниченные проверки работоспособности, не гарантия правильности всех ответов. Поиск и загрузка источников проверены командами приложения, полный запрос — через протокол worker. Сам интерфейс и целевой ноутбук в этих проверках не запускались.

После запуска проверьте: вопрос по знакомому документу → открытие цитаты → отмена длинного ответа → следующий вопрос. Если появится ошибка или ответ долго не приходит, сохраните её текст и сообщите длительность ожидания.

Запуск и скорость на целевом ноутбуке проверяет пользователь. Здесь нет моделей 27B, адаптеров, инструментов обучения и приватных документов.
