## Поставка и интерфейс

Java 25, SOA-сервисы и SWT входят в один основной `Mini-AI.exe`. Изменённые GraalVM/OpenJDK/SVM, CRT, SWT, Windows-адаптер и SQLite связаны статически. Дополнительные DLL приложения, установленная Java/Python/VC Runtime и распаковка исполняемых компонентов не требуются. Импорты и фактические загрузки проверены; библиотеки базовой Windows разрешены. Рядом остаются `docs`, `db`, `model`, найденные относительно фактического EXE, а не cwd/ярлыка. `src/build` не относится к настольной поставке.

Заголовок окна, пустой чат и имя файла — **Mini-AI**. Один исходный ICO — `core/shell/resources/enterpriseai/ui/application.ico`; ресурс EXE и SWT-иконки получены из него, внешняя иконка не нужна. Пыльно-жёлтая палитра, фиолетовые узлы с насыщенностью по числу уникальных соседей, округлённые источники с заголовком и видимый разделитель сохранены. «Граф» находится внутри Canvas справа сверху. Старые пояснения, статус «Готово» и GUI-справка отсутствуют.

В округлённом поле запроса одна круглая кнопка: стрелка отправки в покое, квадрат Stop при обработке. Отдельной «Отмены» нет; реальная отмена worker сохранена. Enter отправляет, Shift+Enter переносит строку. Источники видимы и при пустом состоянии. Ошибки показываются одним принадлежащим приложению окном; модель проверяется при отправке. История чата остаётся только в RAM.

Одинарный клик выбирает документ и показывает имя в неподвижной нижней строке всего окна, двойной — проверяет оригинал и открывает его. Перетаскивание более 5 DIP исключает открытие. Линии связей без стрелок и числовых подписей; направления и доказательства в данных сохранены.

Притяжение непрерывное, сильнее для большей степени; топологическая начальная расстановка заполняет область без жёстких колец. Зазор заснувших узлов — 5 единиц графа, масштабируется с zoom. Абсолютные дедлайны 16 666 667 нс не добавляют время вычислений к каждому шагу. Физика спит до настоящего drag/нового графа. Heartbeat — два цветовых пика за 550 мс примерно раз в 8 с, без изменения координат/радиусов.

Семь записанных source SHA исторической проверки 599 документов и геометрии проверки и три source SHA драйвера точно совпали с новой сборкой: [qualification неизменного subset](build/test-results/mini-ai-348f7b78-historical-subset-qualification.json). ## Исключённые этапы и неизменность данных

Пользователь: «Сделай чтобы приложение называлось miniAI. Помодульную проверку пропусти», затем «Переименуй в Mini-AI» и «В дальнейшем также не делай проверку с разными модулями и версиями приложения». Поэтому нет новых 128 композиций Java / 9 вариантов Native Image и альтернативных версий приложения. `modulesAudit.status=SKIPPED_BY_USER`, `conditions.modules=false`; исторические f392 результаты не объявлены текущими. Runtime-автообнаружение и использование модулей сохранены; исключён именно этап испытаний разных составов/версий.

Process Monitor ранее исключён пользователем из текущего и будущего обязательного конвейера. Семь остальных условий `imports,relocation,search,workers,graph,licenses,data` остаются обязательными; UI также проверен. `conditions.procmon=false`, `verifiedNoWrites=false`. Сохранённые старые PML/CSV/частичный XML и export failures не свидетельствуют об успешной свежей no-write приёмке.

Неизменны **28 230 путей/метаданных**, **7 894 SHA-256 / 6 699 016 308 байт**, оригинальная инструкция модели. **20 336** legacy `db/_runtime` файлов имеют только metadata coverage — полная побайтовая неизменность для них не заявляется. Новых/удалённых/изменённых данных и SQLite sidecar не выявлено. Новый before-functional audit занял **18,390 с**, после QA **16,922 с**, после публикации **16,765 с**. ## Лицензии и пределы подтверждения

Лицензии/notices/source встроены в EXE. `--licenses`, `--component-inventory`, `--third-party-source-stdout` выводят из памяти/потока; внешний вызывающий процесс может сохранить stdout в файл. GraalVM/OpenJDK — GPLv2 с Classpath Exception, SWT — EPL2; условия распространения статического Microsoft CRT остаются обязанностью распространителя. Проверка целостности не является юридической сертификацией.

Настоящая модель, обучение/качество/скорость/память и чистая Windows исключены из этой работы. Целевая платформа Windows 11 x64; испытан ноутбук с 32 ГБ. Будущая заменяемая модель поставляется отдельной папкой `model` с самостоятельным `inference-worker.exe`, manifest и весами без DLL. Она ещё не испытана настоящей генерацией.

Оригинал проверяется по пути внутри `docs`, наличию и SHA версии, затем открывается через Windows Open With. Наличие Office не предполагается; общий viewer не гарантирует переход к точному locator. Windows, защитное ПО, драйверы, подкачка, системная диагностика и внешний просмотрщик могут создавать собственные записи. История в RAM не обещает отсутствия следов в системной подкачке/дампах.
