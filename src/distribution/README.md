# Комплект для целевого ноутбука

`package_laptop.py` собирает в `src/build/laptop-release` ZIP проверенного приложения, всех его библиотек, manifest-комплекта модели без больших весов, полного закреплённого реестра данных и сценария первой подготовки. Бинарный SHA закреплён в сценарии; другой EXE нужно сначала проверить и явно обновить эту привязку.

`Setup.ps1` работает в Windows PowerShell 5.1 без администратора: скачивает семь закреплённых файлов существующих Releases, сверяет размеры/SHA, извлекает только `docs` и `db` по доверенному реестру, проверяет все 6535 файлов и собирает веса штатным `model/Download-weights.ps1`. Старые EXE и инструкции обучения из архивов данных не извлекаются. Различающиеся существующие файлы сохраняются с остановкой подготовки.

Для проверки на чистом каталоге распакуйте стартовый ZIP, затем выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Mini-AI\Setup.ps1 -DownloadsDirectory C:\Mini-AI-downloads -Offline -NoLaunch
```

Каталог загрузок должен содержать семь файлов из `download-assets.json`. После успешной подготовки проверьте поиск и запуск интерфейса фактического EXE. Эта проверка не заменяет запуск на целевом ноутбуке. Повторная подготовка принимает только файлы с теми же хешами.
