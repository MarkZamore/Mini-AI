# Открытие источников

Модуль зависит от контрактов DocumentAccessServiceV1 и Platform, без импорта реализации документов. При отсутствии сервиса документов открытие и его команды отключаются. Проверка SHA-256 и реального пути выполняется вне потока интерфейса. Используется существующая версия оригинала, а не выбранный производный артефакт.

В Windows платформа вызывает Open With с OAIF_EXEC без регистрации ассоциаций. Никакой просмотрщик не устанавливается. Координаты PDF, ячейки и XPath остаются данными цитирования: общий диалог Windows не гарантирует переход к ним. Пользователю следует показывать производное происхождение XPath для DOC/RTF.

Приложение открывает файлы только для чтения при проверке. Внешний просмотрщик самостоятельно открывает путь и может изменять документ, создавать кеши, историю и настройки. Между проверкой версии и внешним открытием существует гонка замены файла; полностью исключить её без изменения режима внешнего просмотра невозможно. После проверки путь сверяется повторно, но это не гарантия запрета записи сторонней программы.

Тесты используют поддельный порт платформы и не запускают внешние программы. Полная проверка Open With, длинных путей, junction и операций реестра выполняется в матрице Windows/Process Monitor.
