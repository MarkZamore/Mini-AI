# Документы и происхождение

Сервис читает существующие таблицы documents/artifacts и канонический JSON. База, оригиналы, производные файлы и отчёты не изменяются. JSON загружается в память с пределом 32 МиБ, строгим UTF-8 и проверкой версии схемы 1.0, ID и SHA-256 версии из индекса. Возвращаемые JSON-структуры глубоко неизменяемы.

Оригинал должен находиться внутри реальной папки docs; JSON и производные артефакты — внутри реальной db. toRealPath разрешает символические ссылки и junction до проверки принадлежности. Абсолютные пути в базе отклоняются. SHA-256 проверяется заново при каждом разрешении; кеш подтверждения версии отсутствует.

Цепочка derived_from проверяется целиком до original. Неизвестный артефакт, цикл, чрезмерная длина цепочки или изменённая версия дают ошибку. В SourceResolution сохраняются отдельно originalPath и выбранный path, locator без перерасчёта координат Unicode и точная цепочка происхождения. Проверка хеша подтверждает файл, но не качество OCR.

Тесты создают только фикстуры src/build. Они проверяют Unicode, пути, версии, отмену, производные цепочки и независимость при удалении сервиса базы. Если Windows не разрешает создание symlink обычному пользователю, этот тест отмечается как недоступный; junction остаётся обязательной приёмочной проверкой.
